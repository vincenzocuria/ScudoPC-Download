# ScudoPC — download ufficiali

**Sviluppatore: Curia Vincenzo** · Windows 10 e Windows 11 a 64 bit.

[Scarica ScudoPC.exe](https://github.com/vincenzocuria/ScudoPC-Download/releases/latest/download/ScudoPC.exe) · [Pacchetto ZIP con guida](https://github.com/vincenzocuria/ScudoPC-Download/releases/latest/download/ScudoPC-Windows-x64.zip)

ScudoPC raccoglie informazioni su firewall, porte, servizi, programmi remoti, VPN conosciute e protezioni Windows. Offre istruzioni per ogni voce, correzioni selezionabili con backup e aggiornamenti verificati.

## Utilizzo

1. Scarica lo ZIP, estrailo in una cartella locale e avvia ScudoPC.exe.
2. Esegui Analizza il PC. Per i controlli protetti riapri come amministratore.
3. Usa Risolvi accanto alle correzioni supportate o Risolvi tutto per vedere una selezione degli interventi applicabili.
4. Consulta la guida per le voci che richiedono una decisione, come VPN, account, condivisioni o programmi sconosciuti.

Gli aggiornamenti vengono controllati all'avvio e ogni 12 ore mentre l'app è aperta. L'installazione richiede conferma e verifica firma del manifest, hash e versione dell'eseguibile. Il controllo automatico si può disattivare.

## Limiti

La diagnosi non certifica l'assenza di intrusioni. ScudoPC non sostituisce un antivirus o un sistema EDR. Gli interventi possono interrompere accessi remoti o dispositivi: leggere gli effetti prima di confermare. Su PC aziendali coinvolgere il responsabile IT.

Questa è una prima release del canale pubblico: test locali e simulati completati; il collaudo amministrativo su tutte le edizioni e configurazioni Windows non è esaustivo. L'EXE non ha firma Authenticode Windows. La firma del canale aggiornamenti è distinta: non disabilitare SmartScreen o antivirus.

I sorgenti sono mantenuti in un repository privato. Questo repository contiene soltanto informazioni e file di distribuzione. Nessun token GitHub è incorporato nel client.
